## 3. App Purpose and Target Audience / 앱 목적 및 타겟 사용자

Gilchi is a landmark-based pedestrian navigation app for South Korea.

[Problem]
Existing pedestrian navigation apps guide users with street names (e.g., "Turn left onto OO-ro"), which are not intuitive for users unfamiliar with the area.

[Value]
Gilchi identifies real-world landmarks (convenience stores, cafes, subway stations, etc.) near each turn point and provides instructions like "Turn right at the convenience store." This makes it easy for anyone to navigate by looking at visible buildings around them.

[Target Audience]
Pedestrians in South Korea, especially those who find it difficult to navigate using street names.

길치(Gilchi)는 한국 내 랜드마크 기반 보행자 내비게이션 앱입니다. 기존 도보 내비게이션은 도로명으로 안내하여 길을 잘 모르는 사용자에게 직관적이지 않습니다. 길치는 회전 지점 주변의 실제 랜드마크(편의점, 카페, 지하철역 등)를 기준으로 안내하여, 누구나 눈에 보이는 건물을 기준으로 쉽게 길을 찾을 수 있습니다. 한국 내 도보 이동자, 특히 길 찾기에 어려움을 겪는 사용자를 대상으로 합니다.

## 4. Instructions for Accessing Main Features / 기능 접근 방법

[Account / Login]
This app does not require any account creation or login. All features are available immediately upon launch.

[How to Use]
1. Launch the app.
2. Search for a destination using the search bar.
3. Select a destination to set it, then a walking route is calculated automatically.
4. Landmarks near each turn point are automatically selected and displayed on the map.
5. Tap the start button to begin navigation.
6. Receive real-time turn-by-turn guidance with landmarks shown on the Lock Screen and Dynamic Island via Live Activity.

[In-App Purchases / Subscriptions]
None. All features are completely free.

이 앱은 로그인이나 계정 생성이 필요하지 않습니다. 앱을 실행하면 즉시 모든 기능을 사용할 수 있습니다. 목적지를 검색하고 선택하면 도보 경로가 자동으로 계산되며, 각 회전 지점에 랜드마크가 표시됩니다. 시작 버튼을 누르면 실시간 안내가 시작되고 잠금화면/Dynamic Island에서 Live Activity로 안내를 확인할 수 있습니다. 인앱 결제 및 구독은 없으며 모든 기능이 무료입니다.

## 5. External Services / 외부 서비스

This app uses the following external services to deliver its core functionality:

1. T map REST API (SK Telecom, South Korea)
   - Pedestrian route calculation
   - Nearby POI (Point of Interest) search for landmark selection
   - Place keyword search

2. Naver Maps SDK (Naver Cloud Platform, South Korea)
   - Map rendering, route polyline display, and landmark marker display

3. Apple Core Location Framework
   - GPS location tracking and compass heading for real-time navigation

No AI services, payment processors, authentication services, or advertising services are used.

이 앱은 T map REST API(SK텔레콤, 도보 경로 계산 및 POI 검색), Naver Maps SDK(네이버 클라우드 플랫폼, 지도 렌더링), Apple Core Location(GPS 위치 추적)을 사용합니다. AI 서비스, 결제 처리, 인증 서비스, 광고 서비스는 사용하지 않습니다.

## 6. Regional Differences / 지역별 차이

This app is available only in South Korea. The core data providers — T map REST API and Naver Maps SDK — provide pedestrian route and POI data exclusively for South Korea. The app does not function outside of South Korea, as route calculation and landmark search are not supported in other regions.

이 앱은 한국에서만 서비스됩니다. 핵심 데이터 제공자인 T map REST API와 Naver Maps SDK가 한국 내 도보 경로 및 POI 데이터만 제공하기 때문에, 해외에서는 경로 계산 및 랜드마크 검색이 지원되지 않아 앱이 작동하지 않습니다.
